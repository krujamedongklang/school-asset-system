📖 วิธีเชื่อมต่อ Supabase:
  1. สร้าง Project ใน supabase.com
  2. รันคำสั่งจากไฟล์ supabase_schema.sql ใน SQL Editor
  3. คัดลอก Project URL และ anon key มาบันทึกด้านบน
